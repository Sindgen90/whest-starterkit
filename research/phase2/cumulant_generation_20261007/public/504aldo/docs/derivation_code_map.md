# Derivation and code map for the designated submission V25 (#329644)

Support document for the Phase 2 algorithmic-contribution write-up. It maps every
mechanism of the shipped estimator to (a) the paper's objects (arXiv:2605.05179, Wu et al.
2026, "factorized K=3 cumulant propagation", supplement S.4.3) and (b) the exact code
block that implements it in `estimator_v25.py` (1131 lines; identical to
`C:\kaggle_local\whest\submissions\v25_adaptlam\estimator.py`). Line numbers refer to
that file as of 2026-09-03 and are approximate (+-3). Numbers quoted for accuracy and
cost come from `reports/insights.md` (finding ids in brackets) and the logs named there.

Conventions used throughout:
- n = 1024 (width), L = 16 (depth), layer index li = 0..15, k = number of live K3
  sources at a layer (one is born per layer, so k = li).
- "unit" = one n x n x n matmul = 2 n^3 FLOPs = 2^31 FLOPs; the budget B = 2^41 = 1024
  units, so x B = units / 1024.
- d(v) = diag(v); A * B = elementwise (Hadamard) product; x (x) y = outer product; Sym =
  symmetrization over the three tensor axes; `_zero_diag(X)` = X with its diagonal zeroed.
- The weight convention: `w32` is the (n_in, n_out) matrix stored in the MLP; the code
  uses `W = w32.T` so that pre-activations are z = W h.

Everything in this file was written by the LLM (Claude) from the code and the findings log.
Statements marked [LLM explanation, not independently validated] are the LLM's reading of
why something works; they are not backed by a derivation or a dedicated experiment.

The paper's factored form (S.4.3 eq. (15)): T_{i1 i2 i3} = (1/6) sum_sigma sum_j
A_{i_sigma(1) j} B_{i_sigma(2) j} C_{i_sigma(3) j} with A, B, C in R^{n x J}. Our hub
source is exactly this with (A, B, C) = (X, P, Y) and J = n. The paper transports all
three legs (3 n^2 J per source-layer) and appends 6n new columns per layer; we keep TWO
transported legs (A and P; Y = A d(w2) is a column scaling of A, X = 3A) plus thin legs,
and ONE new source (n columns) per layer. This is the "7 -> 4 units per source-layer"
restructure of F63 (2 transports + 2 contractions).

## 2. One layer of the estimator, in execution order

All of this is `Estimator.predict` (lines ~415-995) and `Estimator._dslices` (lines
~997-1131). The loop body runs once per weight matrix; the state entering layer li is
(mu, C, the source stacks, the thin stacks, g_prev/var_prev/lam_prev, the shared-basis
state).

### 2.1 Linear transport (lines ~484-500)

    mu      <- W mu                                  (n^2)
    C_pre   <- W C W^T   = einsum("ij,ia,jb->ab", C, w32, w32)     (2 units)
    var     <- diag(C_pre) clamped at 1e-10;  C_off <- C_pre with zero diagonal
    trim (last layer): C_pre is never formed; var <- colsum(w32 * (C @ w32))   (1 unit)

Code: `mu = W @ mu`; `C_pre = fnp.einsum(...)`; in the trim branch
`var = fnp.maximum(fnp.sum(w32 * (C @ w32), axis=0), 1e-10)` (V19). The covariance is
tagged `flops.as_symmetric` when assembled (line ~927) so flopscope bills the sandwich
as a symmetric product [billing detail; F56 audit says standard patterns bill at ratio
1.00 to the theoretical floor].

K3 carriers (lines ~500-620). Every leg of a source born after the previous layer's
ReLU is transported by the SAME map leg <- W d(w1_prev) leg, where w1_prev is the
previous layer's Wick coefficient w(1,1) = Phi (the ReLU "gain" of each neuron). The
code folds d(w1_prev) into the weight once: `WD = W * reshape(w1_prev, (1, -1))`, so
no separate (k, n, n) scaling pass exists. The newborn source (born at the end of the
previous layer with P = I) is transported by the raw W.

    dense young sources s = ka..k-1:   A_s <- WD A_s,  P_s <- WD P_s      (2 units each)
    thin legs:                          Z <- WD Z,  Zf <- WD Zf             (n^2 (r+2), n^2 2 rfb)
    newborn:                            A_new = W a_b,  P_new = W            (1 unit + copy)

Code: `fnp.matmul(WDb, A_st[ka:], out=legs["A1"][ka:k])` and the same for P; `Z_st =
fnp.matmul(WDb, Z_st)`; newborn `fnp.matmul(W, a_b, out=legs["A0"][k])`,
`fnp.copyto(legs["P0"][k], W)`. The legs live in two ping-pong (L-1, n, n) buffers per
leg type (`legs["A0"]/["A1"]`, `legs["P0"]/["P1"]`), swapped each layer (F53: no fresh
(k,n,n) allocations, residual-time reason only; values unaffected).

### 2.2 Old sources: shared basis and nested tier (lines ~504-610; V21/V24)

Sources older than AGE_OLD = 4 transports are not stored densely. The state is
    Qc  (n x r1), r1 = 384   transported basis (pre-wick of the current layer)
    FAo, FPo (ka-kb, r1, n)   static factors of the tier-1 sources: A_s = Qc FA_s, P_s = Qc FP_s
    U   (r1 x r2), r2 = 224   sub-basis of the tier-2 (age > 7) sources: A_s = Qc U FA2_s
    FA2, FP2 (kb, r2, n)      their static factors
    Sg (r1 x r1), S2 (r2 x r2) weighted Gram cores of tier 1 / tier 2 in factor coordinates

Transport of the basis: `Qc = WD @ Qc` (n^2 r1) when no source joins this layer.

Join (exactly one source per layer crosses the age gate, at layers li = 5..14; never at
the last layer): `ka_t = max(ka, min(k, li - age_old))`. The joiner j = ka has dense legs
Aj = d(w1) A_st[j], Pj = d(w1) P_st[j] (post-wick). The new basis is a one-pass
randomized range finder on the weighted leg Gram of (old group + joiner):

    Gram = Aj d(dA) Aj^T + Pj d(dP) Pj^T + Qp Sfull Qp^T,   Qp = d(w1) Qc,  Sfull = Sg + U S2 U^T
    Yq   = Gram Om,   Om = w32[:, :r1]   (the first r1 columns of the layer weight as a fixed sketch)
    Qn   = qr(Yq)                       (n x r1, orthonormal)
    FAj = Qn^T Aj, FPj = Qn^T Pj        (new factors of the joiner)
    Tq = Qn^T Qp;  FAo <- Tq FAo, FPo <- Tq FPo, Sg <- Tq Sg Tq^T, U <- Tq U   (rotation into the new basis)
    Sg <- Sg + FAj d(dA) FAj^T + FPj d(dP) FPj^T
    Qc <- W Qn                          (the wick is already inside Qn)

Code variables: `Aj, Pj, dAj, dPj, Om, Qp, Sfull, Yq, Qn, FAj, FPj, Tq, Sj`; `QPASS`
(=1) is the number of subspace-iteration passes. The column weights dA = 9 + w2^2 + 9 e^2
and dP = 1 + s^2 (recorded at birth in `dA_list`, `dP_list`) are the squared column
scalings with which the A leg and the P leg enter the three legs X1 = 3A, Y1 = A d(w2),
M = P d(s) + 3 A d(e), so that the Gram weights the legs as the contraction sees them.

Nested move (V24; at layers li = 8..14, right after the join, in the orthonormal
coordinates Qn): the oldest tier-1 member (its factors `FA1 = FAo[0]`, `FP1 = FPo[0]`)
moves into tier 2:

    S_s = FA1 d(dA) FA1^T + FP1 d(dP) FP1^T          (r1 x r1 core of the mover)
    G2  = S_s + U S2 U^T                              (core of mover + tier 2)
    Un  = range finder of G2 in r1-space, sketch Om2 = w32[:r1, :r2], QPASS2 = 2 passes
    FA2j = Un^T FA1, FP2j = Un^T FP1;  old FA2 <- (Un^T U) FA2;  S2 = Un^T G2 Un;  U = Un
    donor: FAo <- FAo[1:], Sg <- Sg - S_s

Code variables: `jb, FA1, FP1, dAb, dPb, S_s, G2, Om2, Un, FA2j, FP2j, T2`. The lean
reference does the same thing as "confine age>=4 to rank 384, then age>=7 to rank 256
inside it" (`lean_k3_aug.py` `K3Blocks.confine_old_`, called with a list of tiers).

Forming the dense legs (needed because the (2,1) contraction takes Hadamard products of
legs, which do not factor; F71 audit): tier 1 `einsum("iq,kqn->kin", Qc, FAo)` (2 x
r1/n units per source), tier 2 `QU = Qc @ U` then `einsum("iq,kqn->kin", QU, FA2)`
(2 x r2/n units per source). Written straight into the leg buffers.

### 2.3 The (2,1) and (3,) diagonals of the third cumulant (`_dslices`, lines ~997-1131)

For the sub-blocks B1 = Sym(X1 x P x Y1) with X1 = 3A, Y1 = A d(w2) and B3 = Sym(M x P
x P), the (2,1)-diagonal of Sym(x (x) p (x) y) summed over columns is (1/3)[(X*P) Y^T +
(X*Y) P^T + (P*Y) X^T]. Substituting the column scalings gives the formula in the
`_dslices` docstring:

    D21 = 2 H + T2 + T3/3 + 2 T4/3,   H = (A*P*w2) A^T,  T2 = (A*A*w2) P^T,
                                      T3 = (P*P) M^T,     T4 = (M*P) P^T
    D3[i] = 3 sum_j w2_j A_ij^2 P_ij + sum_j M_ij P_ij^2

(w2 multiplies columns: `W2B` is (k, 1, n)). The M leg is never formed: M*P = (P*P) s
+ 3 (A*P) e + (Z L^T)*P, so everything collapses into two fused "left factors" and two
dense contractions per source:

    LA = 2 (A*P) w2 + (P*P) e          contracted against A^T   -> einsum("kij,kcj->ic", LA, A_st)
    LP = (A*A) w2 + (P*P) s/3 + (2/3) M*P   contracted against P^T -> einsum("kij,kcj->ic", LP, P_st)
    plus the thin term (1/3) (P*P) L Z^T  = einsum("kij,kjq->kiq", PP, L_st) then einsum with Z_st  (n^2 r)

Code: `AP`, `PP`, `MP`, `LA`, `LP`, `PPL`; buffers `bufs["ap"], ["pp"], ["t"], ["mp"],
["la"], ["lp"]` (out= into pooled buffers, F53). D3 is the row sum of the same Hadamard
products: `D3 = einsum("kij,kij,kij->i", A_st, A_st, T) * 3 + einsum("kij,kij->i", MP,
P_st)` with T = P*w2.

V18 feedback terms (rfb > 0): with Xt = F1 R1 and Yt = F2 R2 (rank-16 corrections to X1
and Y1, see 2.6), the docstring formulas add to the left factors and add thin right-factor
terms:

    LP += A*Yt + (1/3) Xt*A*w2 + (1/3) Xt*Yt;   D3 += 3 rowsum(P * LPadd)
    LA += (1/3) Xt*P*w2 + P*Yt
    D21 += (AP + (1/3) Xt*P) R2^T F2^T + (1/3)(AP*w2 + P*Yt) R1^T F1^T     (thin, n^2 rfb)

Code: `Xt`, `Yt` formed from `Zf_st[:, :, :rfb]`, `Zf_st[:, :, rfb:]` and `R1T_st`,
`R2T_st`; `GYR`, `GXR`, `D21_fb`.

Kappa4 feed pair (X3, Y3) and M_t1 (F68, section 2.6): X3 = A d(c1) + P d(c2) (column
scalings, static per source: `c1_list`, `c2_list`), Y3 = y 1^T with y the TRANSPORTED
vector carried as the last Z column (`Yk = Z_st[:, :, rres + 1]`):

    R = (A*P) c1 + (P*P) c2;   D3 += y * R;   D21 += (1/3) R y^T + (2/3) (y (.) X3) P^T

Code: `C1`, `C2`, `Yk`, `R`; the (2/3)(y (.) X3) term is folded into LP before the P
contraction.

Confined sources: the two dense contractions of tier 1 are re-associated through the
factors, `inner = einsum("kij,kqj->iq", LA[kb:ka], FAo) + einsum(..., LP[kb:ka], FPo)`
(2 x r1/n units per source), tier 2 through U (`inner2 ... @ U2.T`, r2/n units), and ONE
trailing `inner @ Qc.T` per layer (n^2 r1). Note the parameter is named `U2` inside
`_dslices` because `U` is a scratch buffer there.

Last layer (`need_d21=False`): only D3 (no left factors, no dense contractions).

### 2.4 The regenerated fourth-order core and its transported diagonal (lines ~628-680)

The augmented-K3 algorithm of the paper carries a fourth-order object; the reference
"r=1 matrix-core" projection reduces it to an n x n core G. F68's measurement: G =
d(g) + lambda C_off with one scalar per layer explains the off-diagonal to R^2 0.66-0.97
(rising with depth) for the post-ReLU fit on 2 dumps; the code uses the PRE-activation law
(G_pre_off = lambda C_pre_off), whose R^2 is ~0.5 at layer 0, >= 0.95 from layer 3 and 0.99
at depth on 8 dumps [corrected 2026-09-22, F105]. G here is the r=1 matrix core, not the
(2,2) slice of kappa4 (the (2,2) slice enters G only through its row sums, on the diagonal). Its transport through the linear layer, W G W^T, has diagonal

    dG = (W*W) g + lambda (diag(C_pre) - (W*W) var)      (n^2; `WW = W * W`)

because W (lambda C_off) W^T = lambda (C_pre - W d(var) W^T) and only the diagonal of
W d(.) W^T is (W*W)(.). The off-diagonal of the transported core is taken as lambda
C_pre_off (the "free port" of F68: the spill of W d(g - lambda var) W^T off the diagonal
is dropped; measured harmless).

V25 adaptive lambda (lines ~640-652): dG is affine in lambda, dG = t_g + lambda t_v with
t_g = (W*W) g_prev and t_v = var - (W*W) var_prev; the code evaluates dG at the table
value, forms rr = mean(dG0)/mean(var), sets

    lam_prev <- lam_prev * clip(rr / REF_R[li-1], 0.5, 2.0) ^ BETA,   then dG = t_g + lam_prev t_v

Code: `t_g, t_v, dG0, rr, ref, lam_prev, dG`. The same `lam_prev` is then consumed by
every use of lambda at this layer (2.5 and 2.6). Cost: one extra n^2 matvec.

Use-side quantities fed to the term table (lines ~653-658):

    g4row = m dG                          (the (4,) slice of the Wick tensor, m = METRIC_C = 2)
    wk4m  = (m/6) (dG_i + dG_j), zero diagonal      (the (2,2) slice)
    wk431 = (m/2) lambda C_off             (the (3,1) slice; 4 extra terms appended to TERM_SPECS at import)

Off-suite (riders False) the code falls back to an isotropic kappa4 scalar `K4_sigma`
(the V1.6 base path); `K4_vec` (vec+ww) is computed but unused since regen supersedes it
on the suite shape.

### 2.5 The Wick/Hermite nonlinear update (lines ~683-770)

Per neuron: sigma = sqrt(var), alpha = mu/sigma, phi = pdf(alpha), Phi = cdf(alpha).
All Wick coefficients at once (unified form, `WICK_UNIFIED`): w(k,p) = const x
sigma^e x (P1(alpha) phi + P2(alpha) Phi), computed as `W_all = ((APOW @ C1) * phi +
(APOW @ C2) * Phi) * (SB @ SELC)` where `APOW` holds powers of alpha, `SB` powers of
sigma, and `C1, C2, SELC` are the polynomial coefficient tables built once in
`_build_wick_consts`. These are exact ReLU Hermite/Wick coefficients (the lean
`WickCache` computes the same numbers from `WICK_POLYS` and `HE_COEFS`), not fitted.

Term program: for each output slice the power cumulants are

    pK[int_part][i,(j)] = sum over terms t   coef_t x slice_a(t)[i,j] x slice_b(t)[i,j] x w_left(t)[i] x w_right(t)[j]

with slices from {ones, C_off, D21, D21^T, D3 row/col, g4 row/col, wk4m, wk431}
(`TERM_SPECS`; `b2`/`b1` dicts) and Wick columns selected by `SL2/SR2/SL1`. The d=2
outputs are one fused einsum over the stacked products (`ABstack`, written into the
persistent `abbuf`): `PK2 = einsum("tij,ti,tj,tg->gij", ABstack, WL2, WR2, IND2)`; the
d=1 outputs `PK1 = einsum("ti,ti,tg->gi", B1stack, WL1, IND1)`. Then `pk11`, `pk22` are
symmetrized and de-diagonalized, and `PK2K_TABLE` converts power cumulants to cumulants
(`K`): e.g. K[(2,)] = pK(2,) - pK(1,)^2, K[(2,1)] = pK(2,1) - 2 pK(1,0) pK(1,1). Output
of the layer: `mu = K1v` (the post-ReLU mean, appended to `rows`), `C = diagflat(K2v)
+ sym(K11)`.

At the last layer only the d=1 program runs (mode `trim`), and the mean `pk1v` is
appended directly (line ~787: `rows.append(pk1v)`; the pK -> K step is the identity for
(1,)).

The three "modes" of the term program: mode 0 = no K3 yet (layer 0; slices d3/d21/g4
absent), mode 1 = full, mode 2 = full without the wk431 terms (used when `regen` is off).

### 2.6 Birth of the new source (lines ~790-960)

Before the next linear layer, the third cumulant produced by this ReLU is written as a
new hub source with P = I. Wick scalings of the OLD content that re-enter the next
layer's factors: `w1 = W_all[:, (1,1)]`, `w2 = W_all[:, (2,1)]`, `w1_prev = w1`
(picked up by WD next layer), and the old slices scaled as `D3_w = D3 w1^3`, `D21_w =
d(w1) D21 d(w1) ... ` (`(w1col * w1col) * D21 * reshape(w1, (1,-1))`).

Birth factor: `a_b = w1col * C_off` = d(w1) C_off (n x n). Sub-block B1: X1 = 3 a_b +
Xt, Y1 = a_b d(w2) + Yt where (V18, F69) the feedback of the current D21 into the
factors is Xt = 1.5 d(w2) D21 and Yt = 0.5 d(w1) D21^T d(w3) (the lean chain's `X1 =
3(c_w1 WK11 + c_w2 WK21)`, `Y1 = (c_w2 r_w1 WK11 + c_w3 r_w1 WK21 + ...)^T` with the WK22
struct term dropped, `no_wk22_fac`, and B2 dropped, `shadow_B2` -- both measured at
0%/negative on this base, F69). D21 is compressed to rank R_FB by a randomized range
finder (`Omf = w32[:, :rfb]`, two QR passes: `Yf = D21 @ Omf; Qf = qr; Yf = D21 @
(D21.T @ Qf); Qf = qr`, `Bf = Qf.T @ D21`), giving the thin legs F1 = d(w2) Qf, F2 =
d(w1) Bf^T and static right factors R1 = 1.5 Bf, R2 = 0.5 Qf^T d(w3). Birth dslices of
B1 with P = I (n^2 closed forms): `D21_new = (xd Y1^T + X1*Y1 + yd X1^T)/3`, `D3_new =
xd yd` with xd, yd the diagonals of Xt, Yt (diag(a_b) = 0).

Kappa4 -> K3 feed (F68; the reference augmented algorithm's terms 1 and 3 with the
r=1 core): X3 = d(w1) G d(w1) = lambda a_b d(w1) + P d(w1^2 dG) = A d(c1) + P d(c2) with
c1 = lambda w1 (`c1_b`), c2 = w1^2 dG (`dgw`); Y3 = (m/4) w2 1^T (`y_b`); M_t1 = (m/4)
(w2*dG)(w1^2)^T (`u_b`, `w1sq`). Their birth dslices are added to `D21_new`, `D3_new`
in closed form (lines ~840-850). The lambda used here is the pre-activation lambda of
THIS layer (`lam_prev`, after the V25 adaptation), because the kappa4 that feeds the
newborn K3 is the one of the current pre-activation.

The M leg: `S3c = K3v - D3_w - D3_new` and `S21 = _zero_diag(K21 - rep21)` (the
post-ReLU (2,1) slice minus the part already represented by the transported old sources
and the newborn hub), then M_b = d(S3c) + 3 S21^T. S21 = S_sep + Rres with the exact
leading term S_sep = d(e) C_off d(w1), e = w(1,2) - 2 pK(1) w1 (`e_b`; a column scaling
of a_b, rides on the A leg for free) and the residual Rres compressed to rank R_RES by
the same range-finder recipe (`Om = w32[:, :r]`, `Q`, `Bm = Q.T @ Rres`). Hence M = P
d(s) + 3 A d(e) + 3 Z L^T with `Rr_full = [3 Bm^T | u_b | y_b]`, `Lr_full = [Q | w1sq |
0]` (the last column carries the transported y vector of Y3 with a zero L column so it
never enters the M-leg einsums -- the V17 port bug #1 of F68).

`newborn = (a_b, Rr_full, Lr_full, S3c, e_b, Ff_b)` is consumed at the next layer's
transport (2.1). Per-source statics appended: `w2b_list`, `s_list` (S3c), `e_list`,
`c1_list`, `c2_list`, `y_list`, `dA_list`, `dP_list`, `R1T_st`, `R2T_st`.

Post-ReLU kappa4 diagonal for the next layer (regen): `g_prev = cA (K4v + K22 1) + cI
(sum K4v + sum K22 1)` (the r=1 harmonic projection with the closed-form n-dependent
coefficients cA = 6/(n+4), cI = -3/((n+2)(n+4)) of `_statics`), `var_prev = K2v`,
`lam_prev = LAM[li]` (table value; adapted at the next layer).

### 2.7 Final-layer trim (V19, F71)

At li = L-1: no C_pre, no D21 (`need_d21=False`), no d=2 term program; the output is
`pk1v` from the d=1 program with slices var, D3, g4row. Saves the two dense contractions
of all k = 15 sources (30 units) and the C_pre sandwich (1 unit). `V19_FULL_LAST=1`
restores the V18 op stream bit-for-bit. Ablation: dropping the last layer's source
machinery entirely (D3 := 0) is 10x worse (F71): the final pre-activation's skew is
essential.

- `riders = (n == 1024 and L == 16)`: only the Phase 2 suite shape gets the regen channel

validated fact (hedge them in the PDF or drop them):
1. "G_off is proportional to C_off because the fourth cumulant is generated from the
   covariance by the ReLU" -- the R^2 of the fit is measured (pre-activation 0.5 -> 0.99 by depth, F105), the mechanism
   is an interpretation. [LLM explanation, not independently validated]
2. F75's reading "more kappa4 diagonal at fixed variance means a larger off-diagonal
   core" -- the correlation is measured; the causal reading is not.
3. "Old sources live in a shrinking subspace because repeated transport by W d(w1)
   concentrates their column space" -- the age law (r/n ~ 3/8 at age 4, ~7/32 at age 7)
   is measured; no derivation exists. [LLM explanation, not independently validated]
4. "The M-leg residual Rres is numerically low-rank" -- measured (rank 16-64 keeps mse
   at parity), no derivation of why.
5. The eps^2 law (extra mse ~ 4.2e-6 eps^2, eps = relative D21 error) is a fit through
   four measured points (F71); it is a summary, not a theorem.
6. The interpretation of the leaders' methods (F67, F74, F76) is inference from public
   scores and one Phase 1 write-up; do not present it as fact.
7. The pruning threshold 1e-5 (62 of 90 terms) is a numerical choice validated by one

8. flopscope's pricing of `qr` and of symmetric-tagged products is taken from the

   decomposition consistent with the measured 0.3667 x B, not an audited ledger.

Things the user must be able to explain from this map without the LLM:
- why the covariance diagonal is exact (power cumulants) while off-diagonals are
  closure-approximated (the paper's adjustment 1);
- why every leg of a source is transported by the same map W d(w1) and why folding w1
  into WD is exact (linearity of the transport; w1 is the previous layer's ReLU gain);
- why forming the (2,1) diagonal needs Hadamard products of dense legs (section 2.3) and
  hence why the old-source factors must be re-densified (the cost floor argument, F71);
- the three roles of lambda at a layer (transported diagonal dG, the (3,1) use-side
  slice wk431, and the feed factor c1 of the newborn) and why they share one value;
- what the range finders do (rank-r approximation of D21 and of Rres at birth, of the
  weighted leg Gram at a join) and why the sketch is a slice of the layer weight (a
  fixed, data-independent, deterministic choice that needs no random numbers);
- what is lost at each approximation: shadow_B2 and no_wk22 (measured 0%/negative),
  Rres rank 16 (+1.6% vs dense), feedback rank 16 (0% vs dense), confinement (+3.4% raw
  on 8 dumps), nested tier (+1.2%), frozen-vs-per-MLP lambda (-0.3% recovered by V25).
